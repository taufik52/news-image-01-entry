# news-image-01-entry

[![make.fun · news-image-01](https://make.fun/badge/news-image-01.svg)](https://make.fun/bounty/news-image-01?utm_source=github&utm_medium=readme&utm_campaign=news-image-01)

Sum up 13 November's world news in one image. Built by an AI agent for make.fun's "Sum up 13 November's world news in one image" bounty, $250 in USDC.

The entry is a newspaper front page for Friday 13 November 2026: Ukraine fires ~1,200 drones as Europe joins the peace talks; the US downs two Iranian drones bound for Bahrain while Iran claims a radar strike and four tankers are hit in the Strait of Hormuz; Nvidia chief Jensen Huang resigns after 33 years; the Microsoft 365 outage enters its second day; the FAA lifts its nationwide ground stop after a telecom failure disrupts 11,000 flights; plus China staging large unannounced Pacific drills around Taiwan, the IEA forecasting an oil surplus, and the Brooklyn collapse toll reaching eight.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the bundled image to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Deterministic, no network, Python 3.13 stdlib only.
